**Button** — the brand's editorial pill action control; terracotta filled = primary CTA, ink outline = secondary. Use for "Book Now", "Explore the Blog", form submits.

```jsx
<Button variant="primary" size="lg" arrow>Reserve your seat</Button>
<Button variant="secondary">Read the story</Button>
```

Variants: `primary` (terracotta), `secondary` (ink outline), `ghost`, `teal`. Sizes `sm|md|lg`. Props: `arrow`, `fullWidth`, `disabled`, `href`/`as` for links. Labels always render uppercase + letterspaced.
