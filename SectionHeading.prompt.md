**SectionHeading** — eyebrow + display headline + italic serif lede. Standard block that opens a section.

```jsx
<SectionHeading eyebrow="The Retreat" title="Ten days to build slower" lede="An unhurried offsite for women founders." align="center" size="xl" />
```

Props: `eyebrow`, `title`, `lede`, `align`, `size` (md/lg/xl/display), `tone` (use `paper` on dark).
